# Pedro Connect

Pedro Connect is a simple social networking web app built with HTML, CSS, and JavaScript. It provides authentication, posting, search, profiles, likes, comments, and follow functionality through Supabase.

## Tech stack

- HTML
- CSS
- JavaScript
- Supabase

## Project structure

- `index.html` — application layout and entry point
- `css/style.css` — application styling
- `js/` — application logic and Supabase configuration

## Running locally

Serve the project with any local web server, then open `index.html` in your browser. Configure the Supabase values in `js/supabase-config.js` before using authentication and data features.
